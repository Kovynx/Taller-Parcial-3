## Reglas Técnicas Clave
1. **Dos programas:** C/C++ (puede usar `GotoXY()`) y Python.
2. **Propósito visual:** Al insertar o eliminar un dato, mostrar visualmente el ordenamiento y el balanceo (rotaciones) del árbol AVL.
3. **Recorridos siempre visibles:** Pre-orden, In-orden y Post-orden visibles en todo momento.
4. **Operaciones obligatorias:** Creación, inclusión (insertar), eliminación, desactivación, consulta (buscar), modificación y persistencia.
5. **Inicio con persistencia opcional:** El usuario decide si cargar datos desde archivo o iniciar vacío.
6. **Modelo:** Identificar explícitamente variables de entrada y salida.
